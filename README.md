# SRR: Selective Router Repair for Merged MoE LLMs

Official implementation of **Selective Router Repair (SRR)** for *Routing Drift Is Not Routing Failure*. SRR selects stable expert pairs and fits router corrections on fixed continuations generated by the merged model.

## Repository Structure

```text
src/srr/                 SRR implementation and checkpoint tools
configs/                 Example configuration files
tests/                   Core numerical tests
```

## Installation

Use a CUDA environment compatible with your MoE checkpoint, then install:

```bash
pip install -e .
```

FlashAttention 2 may be required by the model implementation.

## Usage

1. Set model and output paths in [`configs/srr.example.json`](configs/srr.example.json), then change `status` to `frozen`.
2. Prepare a JSONL file of calibration prompts (format below).
3. Generate parent continuations, build SRR, and materialize the repaired checkpoint:

```bash
srr-cache --protocol configs/srr.example.json --configuration average --prompts /path/to/prompts.jsonl --gpu 0
srr-build --protocol configs/srr.example.json --configuration average --gpu 0
srr-overlay --candidate /path/to/output/average-srr --output /path/to/output/average-srr-model --gpu 0
```

Each command refuses to overwrite an existing output. For other architectures or merging methods, change the roles, source checkpoints, and parent path in the config. Optional Average, Task Arithmetic, TIES, and DARE parent construction is available through `srr-merge-baselines` and [`configs/merges.example.json`](configs/merges.example.json).

## Data Format

Each prompt is one JSONL record with a unique `uuid`, a domain `role`, a `split` (`train` or `validation`), and tokenizer-specific `prompt_ids`:

```json
{"uuid":"sample-001","role":"math","split":"train","prompt_ids":[1,42,73]}
```

Model checkpoints and calibration data are not included.

## Evaluation

Use the [RoMA evaluation code and configurations](https://github.com/tianyi-lab/RoMA) to evaluate each merged parent and its SRR checkpoint under the same benchmark settings.
